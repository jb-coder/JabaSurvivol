# Third-Party Notices

This file records third-party assets, fonts, audio, and code used by JabaSurvivol.

No third-party game assets are included. All shipped art is first-party and
generated by `tools/ArtGenerator`.

## Build tooling

| Name | Version | Source | License | Use |
|---|---|---|---|---|
| SkiaSharp | 4.156.0 | https://github.com/mono/SkiaSharp | MIT | PNG rasterization in `tools/ArtGenerator` only |
| SkiaSharp.NativeAssets.Linux.NoDependencies | 4.156.0 | https://github.com/mono/SkiaSharp | MIT | Linux CI native runtime for the generator |
| SkiaSharp.NativeAssets.Win32 | 4.156.0 | https://github.com/mono/SkiaSharp | MIT | Windows native runtime for the generator |

The SkiaSharp packages are build-time dependencies. They are not shipped in the
Unity player or the Android APK.

Every asset added to the project must include:

- Asset name and version.
- Source URL.
- Author or publisher.
- License.
- Attribution requirements.
- Date added.

Only assets with clear, compatible licenses may be committed.
