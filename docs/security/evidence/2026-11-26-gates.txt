## Unity and Android evidence

The Unity editor is not run by this audit. Android release configuration is
verified from tracked source and the generated release merged manifest:

- `Assets/Plugins/Android/AndroidManifest.xml` declares only `INTERNET` and
  `VIBRATE` permissions.
- The release merged manifest contains exactly one exported component:
  `com.unity3d.player.UnityPlayerActivity`, with the `MAIN`/`LAUNCHER` filter.
  There are no services, receivers, or providers.
- No `android:debuggable`, `android:usesCleartextTraffic`, or network security
  config override is present.
- `ProjectSetup` sets IL2CPP, ARM64, minimum API 26, target API 36, and
  `InsecureHttpOption.NotAllowed`.
- `BuildScript.BuildAndroid` sets `EditorUserBuildSettings.development = false`.
  The separate emulator build is the only development build and enables
  x86_64 plus development-only insecure HTTP for loopback/emulator hosts.
- `GameBootstrap` development scenarios are compiled under
  `#if DEVELOPMENT_BUILD` and are absent from the production build.
- OpenAPI is mapped only when `app.Environment.IsDevelopment()`. The production
  ConfigMap sets `ASPNETCORE_ENVIRONMENT=Production`.

Excerpt: `2026-11-26-android-manifest.txt`.
