## Tracked secret-like files

Command:

```powershell
git ls-files | Select-String -Pattern '\.(keystore|jks|pem|pfx|p12|key|pfx)$|(^|/)secrets(/|$)|(^|/)\.env(\.|$)'
```

Result:

```text
.env.example
deploy/secrets/README.md
```

- `deploy/secrets/README.md` is documentation and contains no secret value.
- `.env.example` is the documented local development template. It contains a
  local PostgreSQL default (`postgres`/`postgres`) and empty telemetry values.
  It is not a real environment file, and `.gitignore` excludes real `.env` files.
- No keystore, `.jks`, `.pem`, `.pfx`, `.p12`, or private key file is tracked.

## Runtime secret handling

- `Jwt__SigningKey` is generated per AppHost run or supplied from the
  `jabasurvivol-secrets` Kubernetes Secret. It is not committed.
- `ConnectionStrings__Database` is supplied from the Kubernetes Secret or the
  local environment. It is not committed.
- The Unity client stores only the refresh token, through Android Keystore
  (AES/GCM) or Windows DPAPI. Access tokens stay in memory.
- Logs and evidence use redacted or fixed messages. No token, password, or
  connection string value is printed by this audit.
