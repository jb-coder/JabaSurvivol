# v0.1.0 Walking Skeleton

- Release date: 2026-11-06
- Tag: `v0.1.0`
- Milestone: v0.1.0 Walking Skeleton
- Branch flow: `release/v0.1.0` -> `main`, then backmerge to `develop`

## Summary

First public version of JabaSurvivol. It delivers the repository foundation and
the first playable Android walking skeleton: a landscape top-down arena with
twin-stick touch controls, one zombie, shooting, health, supplies, XP, rounds,
pause, game over, restart, and persistent local progression.

## Included

- Unity 6.3 Universal 2D project with URP 2D rendering and safe-area-aware UI.
- Android IL2CPP ARM64 build configuration (target API 36, minimum API 26).
- Windows IL2CPP and WebGL IL2CPP configuration.
- Shared core package `com.jabasurvivol.core` backed by `src/Game.Core`.
- Persistent profile schema version 1 with atomic writes and backup recovery.
- .NET 10 Aspire solution, service skeletons, contracts, and health endpoints.
- CI, PR policy, security scanning, project automation, and independent reviewer
  approval.
- EditMode and PlayMode tests, Android build automation, and emulator smoke
  evidence.

## Known issues

- Unity CI remains disabled until `UNITY_CI_ENABLED` and the Unity license
  secrets are configured.
- The emulator smoke test used the ARM64 + x86_64 emulator APK; the production
  ARM64-only APK still needs a physical ARM device test.
- The MVP content after the walking skeleton is not implemented yet: armory,
  skill tree, four weapons, boss, ten rounds, and round rewards.
- Runtime art is procedural placeholder art.
- Localization and monetization are intentionally deferred to later milestones.

## Save compatibility

- Save schema version: 1.
- Fresh installs create a new profile.
- Death resets only the current run; supplies, XP, level, skill points, and
  records persist.
