# v0.6.0 Localization

- Release date: 2026-11-13
- Tag: `v0.6.0`
- Milestone: v0.6.0 Localization
- Branch flow: `release/v0.6.0` -> `main`, then backmerge to `develop`

## Summary

JabaSurvivol now ships with English and Spanish. The game follows the device
language by default, offers a runtime language selector with a system-default
option, and keeps the chosen locale across launches. The Spanish table and
glossary were human-reviewed and approved on 2026-11-13.

## Included

- English and Spanish locale tables with 196 keys each.
- Device-language default and persisted manual override.
- Language selector in the main and pause menus with system default, English,
  and Español.
- Live refresh of static labels and dynamic HUD text without resetting the
  current run.
- Localized leaderboard rows, account messages, cloud status, and identity
  error codes.
- Safe English fallback for missing keys and a generic localized message for
  unknown backend error codes.
- Key parity, non-empty value, placeholder parity, fallback, pseudo-locale, and
  phone/tablet layout checks.
- A 20-image English/Spanish phone and tablet screenshot matrix.
- Translation workflow, glossary, pending/approval record, and per-locale
  release gate.
- Text best-fit and spacing adjustments for expanded locales.
- Android and core package version `0.6.0` with version code `7`, IL2CPP, and
  ARM64.

## Known issues and deferred work

- Online features still require a reachable backend configured at build time.
  The release APK does not bake a backend URL.
- Character-sheet layout is outside the #141 pseudo-locale audit and screenshot
  matrix. It remains a documented gap for later expanded-locale QA.
- Result screenshots are game-over screens; round-end layout is covered by the
  PlayMode pseudo-locale audit.
- Android per-app language and font fallback remain deferred to #144.
- Physical-device profiling and human playtesting remain future work.
- No VPS, cloud resource, payment flow, premium currency, loot box, or paid
  reward is included.
- Additional locales beyond English and Spanish remain out of scope.
