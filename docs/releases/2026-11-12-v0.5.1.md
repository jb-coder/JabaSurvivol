# v0.5.1 Local Beta

- Release date: 2026-11-12
- Tag: `v0.5.1`
- Milestone: v0.5.1 Polish and Local Beta
- Branch flow: `release/v0.5.1` -> `main`, then backmerge to `develop`

## Summary

First local beta of JabaSurvivol. It adds the online account, cloud-save,
leaderboard, telemetry, remote-config, and BFF layer, plus the local beta
hardening, audio cues, save recovery, and Android packaging work needed for a
private test. The beta runs locally over Tailscale. No VPS, Oracle cluster, paid
cloud resource, payment flow, or premium currency is included.

## Included

- Username/password accounts with case-insensitive unique usernames, ASP.NET Core
  Identity password hashing, short-lived access tokens, and rotating refresh
  tokens stored as hashes.
- Registration, login, refresh, logout, and current-account endpoints under
  `/api/v1/identity`, with per-IP rate limiting and ProblemDetails responses.
- Revision-safe cloud saves with ETags, a 1 MiB limit, schema validation, and
  `409` conflicts that never overwrite newer data.
- Highest-round leaderboard with idempotent run submission, bounds validation,
  best run per account, a top-50 default query capped at 100, deterministic
  tiebreaks, and per-account rate limiting.
- Public read-only remote config with minimum client version, operational flags,
  sample rate, ETag support, and startup validation.
- Authenticated telemetry ingestion with typed allowlists, idempotency, and no
  PII, plus a worker that aggregates daily totals and retains raw events for 30
  days.
- BFF public boundary with YARP routing, JWT validation, per-IP and per-account
  rate limits, correlation IDs, and safe ProblemDetails on failures.
- Unity account panel with register, login, logout, loading, signed-out,
  signed-in, and offline states.
- Access tokens kept in memory only; refresh tokens encrypted with Windows DPAPI
  or the Android Keystore and never written to `PlayerPrefs`.
- Unity cloud-save backup and restore with explicit conflict choices, bounded
  retries, and offline fallback.
- Unity highest-round leaderboard from the main menu and victory screen.
- Opt-in telemetry with a persistent toggle, allowlisted events, batched
  retries, and remote-config gating that defaults to off.
- Procedural audio cues for hit, kill, level-up, reward, victory, and defeat,
  with a persistent pause-menu mute toggle.
- Main-menu version and build-commit display for beta feedback.
- Save recovery from the backup file when the main save is empty, unreadable, or
  missing.
- Hardened multi-stage backend images and Kustomize manifests with non-root
  containers, probes, resource budgets, network policies, and BFF-only ingress.
- Local Aspire AppHost waits for PostgreSQL and upstream services before starting
  dependent projects.
- Android and core package version `0.5.1` with version code `6`, IL2CPP, and
  ARM64.

## Known issues and deferred work

- The five-person beta participation goal, physical-device profiling, combat
  tuning from beta feedback, and the remaining external network probe checks are
  moved to the `v0.5.2 Beta Follow-ups` milestone (#98, #99, #101, #108).
- Online features require a running backend. The release APK does not bake a
  backend URL, so cloud saves, leaderboards, telemetry, and remote config stay
  unavailable until a configured build points at a reachable BFF.
- Localization is English-only until `v0.6.0`.
- No VPS or Oracle resource is provisioned. The eventual VPS handoff remains a
  final-handoff task.
- No payments, premium currency, Cores, cosmetic store, or in-game purchases.
- Optional donations are not part of this release.
