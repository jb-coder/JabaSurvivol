# v0.3.0 Armory and Skills

- Release date: 2026-11-07
- Tag: `v0.3.0`
- Milestone: v0.3.0 Armory and Skills
- Branch flow: `release/v0.3.0` -> `main`, then backmerge to `develop`

## Summary

Third public version of JabaSurvivol. It adds the persistent armory and the
character build layer: five weapons, permanent weapon upgrades, three armor
tiers with damage absorption, a nine-node skill tree, a character sheet, and
extended headless balance coverage.

## Included

- Data-driven weapon catalog for Pistol, SMG, Shotgun, Rifle, and LMG with
  damage, fire rate, magazine, reload, range, reserve ammunition, and unlock
  cost.
- Persistent weapon unlocks and equipped weapon, with the Pistol always
  available and infinite reserve.
- Armory weapon shop and equip flow from the main menu and pause menu, with
  touch-friendly rows.
- Combat uses the equipped weapon's damage, fire interval, range, projectile
  speed, pellet count, and spread.
- Five permanent upgrade tiers per weapon for damage, fire rate, magazine size,
  and reload speed, with atomic purchases and effective stat aggregation.
- Light, Medium, and Heavy armor tiers with absorb values, unlock costs, and
  five permanent upgrade tiers per armor.
- Run armor absorbs damage before health, resets to maximum on a new run, and is
  repaired by free armor plate drops.
- Armory armor tab with unlock, equip, and upgrade actions, plus a HUD armor
  readout.
- Nine-node Strength, Agility, and Survival skill tree with five ranks per node
  and Turret rank data.
- Skill point allocation, free respec between runs, active skill slot
  persistence, and the 35-point level 30 progression rule.
- Deterministic stat aggregation across base stats, skills, weapon upgrades,
  armor, and temporary modifiers, with movement speed, damage, armor, critical
  chance, and headshot caps.
- Character sheet with phone branch tabs, tablet three-column layout, rank pips,
  large touch targets, and before/after stat previews.
- Character sheet access from the main menu, pause menu, and round-end screen.
- HUD level, XP progress, available skill points, and a temporary level-up
  notification.
- Extended balance simulation for the v0.3.0 build path with weapon, armor,
  skill, economy, progression, and outlier reporting.
- Android version `0.3.0`, version code `3`.

## Known issues

- Unity CI remains disabled until `UNITY_CI_ENABLED` and the Unity license
  secrets are configured. Issue #27 remains blocked.
- Round 10 clears without a boss encounter or victory state. The boss and MVP
  completion flow remain in later scope.
- Ammo, magazine, and reload values are modeled and displayed, but runs do not
  yet consume ammunition or trigger reloads.
- Shockwave, Dash, and Turret rank data exists, but active skill activation and
  synergies are not implemented yet.
- Armor is represented by HUD and character-sheet values; armor visuals are
  still procedural placeholders.
- The balance simulation uses one deterministic rifle-first build. It validates
  pacing and progression, but it does not replace a human playtest.
- The production ARM64-only APK still needs a physical ARM device test.
- Runtime art is procedural placeholder art.
- Localization and monetization are intentionally deferred to later milestones.

## Save compatibility

- Save schema version: 1.
- Fresh installs create a new profile.
- Weapon unlocks, equipped weapon, weapon upgrades, armor unlocks, equipped
  armor, armor upgrades, skill allocations, and the active skill slot persist
  across death.
- Death resets only the current run: health, armor, round, position, enemies,
  and run-only resources.
- Schema changes are additive, so existing v0.1.0 and v0.2.0 profiles remain
  compatible.
