# v0.4.0 Content and Boss

- Release date: 2026-11-08
- Tag: `v0.4.0`
- Milestone: v0.4.0 Content and Boss
- Branch flow: `release/v0.4.0` -> `main`, then backmerge to `develop`

## Summary

Fourth public version of JabaSurvivol. It completes the MVP combat loop with
three zombie archetypes, elite rounds, a round 10 boss and victory flow, finite
ammunition and weapon switching, three active skills, and three skill synergies.
The headless balance simulation now covers content, boss time-to-kill, ammo
pressure, skills, and synergies.

## Included

- Walker, Runner, and Brute archetypes with deterministic round composition and
  archetype-specific health, speed, contact damage, supplies, XP, and visuals.
- Elite rounds every fifth round with increased health, contact damage, rewards,
  and a HUD modifier.
- Round 10 boss encounter, The Warden, with a telegraphed slam, enrage phase,
  boss HUD, and a boss spawn gate.
- Victory state with run summary, next-run action, main-menu action, and
  highest-round recording.
- Run-only weapon loadout with per-weapon magazines, finite reserves, manual and
  automatic reload, and weapon switching.
- Ammo crates refill every finite reserve without spending persistent supplies.
- Turret active skill with rank gating, target acquisition, rank-scaled damage
  and duration, cooldown, and a HUD button.
- Dash active skill with rank-scaled distance, cooldown, and brief
  invulnerability.
- Shockwave active skill with rank-scaled area damage, radius, cooldown, and
  knockback.
- Active-skill selection from the armory or character sheet with persistent
  profile storage and zero-rank gating.
- Berserker, Ghost, and Bastion synergies with character-sheet status display.
- Balance simulation coverage for archetypes, elites, boss time-to-kill,
  magazines, reserves, reloads, weapon switching, ammo crates, active skills,
  and synergies.
- Android version `0.4.0`, version code `4`.

## Known issues

- Unity CI remains disabled until `UNITY_CI_ENABLED` and the Unity license
  secrets are configured. Issue #27 remains blocked.
- The production ARM64-only APK still needs a physical ARM device test.
- The APK uses the Unity default signing configuration. Play Store signing is
  not configured.
- The emulator smoke test verifies startup, menu, gameplay, and game-over
  layouts. Boss, active-skill, and synergy behavior is covered by the PlayMode
  suite.
- The balance simulation uses a deterministic build and does not replace a human
  playtest. The default profile reaches level 9 with one unspent skill point;
  active-skill allocation is covered by a ranked test profile.
- Runtime art is procedural placeholder art.
- Backend, online services, telemetry, localization, and monetization remain in
  later milestones.

## Save compatibility

- Save schema version: 1.
- Fresh installs create a new profile.
- Weapon unlocks, equipped weapon, weapon upgrades, armor unlocks, equipped
  armor, armor upgrades, skill allocations, active skill slot, supplies, XP,
  level, and highest round persist across death.
- Death resets only the current run: health, armor, round, position, enemies,
  run-only ammunition, active-skill cooldowns, and synergy timers.
- Schema changes are additive, so existing v0.1.0, v0.2.0, and v0.3.0 profiles
  remain compatible.
