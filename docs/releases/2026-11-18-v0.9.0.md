# v0.9.0 Touch, Settings and Accessibility

- Release date: 2026-11-18
- Status: Ready for release
- Tag: `v0.9.0`
- Milestone: v0.9.0 Touch, Settings and Accessibility
- Branch flow: feature PRs -> `develop`, then `release/v0.9.0` -> `main`, then backmerge to `develop`

## Summary

v0.9.0 turns the touch and accessibility settings into working game behavior. It
adds one settings panel for audio, language, controls, and accessibility; a
left-handed HUD; joystick size and opacity; optional aim assist; manual fire;
Android haptics; reduced motion; colorblind-safe boss telegraphs; confirmation
dialogs for destructive actions; and a first-run help panel.

The persistent progression rules are unchanged. Death still ends only the
current run and keeps supplies, XP, levels, skill points, skills, weapons,
upgrades, and armor.

## Included

- Unified settings panel reachable from the main menu and pause menu.
- Device-local settings for left-handed layout, joystick size, joystick
  opacity, aim assist, auto-fire, reduced motion, haptics, and colorblind-safe
  telegraphs.
- Left-handed HUD that mirrors the sticks and action buttons and updates the
  controls hint.
- Manual fire control when auto-fire is disabled.
- Aim assist with Low and High cones and range fallback.
- Android haptics for player damage, boss slam, and round clear.
- Reduced motion that disables bloom and vignette.
- High-contrast boss telegraph outline when colorblind-safe telegraphs are on.
- Confirmation dialogs for respec and for leaving an active run.
- First-run help panel with the core loop, controls, rewards, armory, and
  persistent-progression promise.
- Effects volume exposed in the settings panel.
- Android and core package version `0.9.0` with version code `12`.
