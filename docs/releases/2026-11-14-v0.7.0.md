# v0.7.0 Art and Visual Polish

- Release date: 2026-11-14
- Tag: `v0.7.0`
- Milestone: v0.7.0 Art and Visual Polish
- Branch flow: `release/v0.7.0` -> `main`, then backmerge to `develop`

## Summary

The v0.7.0 release replaces the prototype primitives with a first-party neon
art set for actors, weapons, projectiles, combat effects, the arena, UI icons,
and the Android application icon. Gameplay rules, balance, hitboxes, ammo, and
persistent progression are unchanged.

## Included

- Deterministic `tools/ArtGenerator` pipeline with 66 committed sprites, a
  SHA-256 manifest, contact-sheet output, and integrity tests.
- Manifest-driven Unity import settings, character/weapon/UI atlases,
  `ArtCatalog`, and named sorting orders.
- Modular player, Walker, Runner, Brute, Warden, and turret rigs with procedural
  walk, aim, recoil, elite aura, and enrage feedback.
- Distinct pistol, SMG, shotgun, rifle, and LMG silhouettes with per-weapon
  projectile, muzzle flash, impact, and turret visuals.
- Tiled neon arena floor, walls, and deterministic non-colliding props.
- Authored HUD, armory, reward, and active-skill icons.
- Android application and adaptive icon.
- Development performance probe, bilingual emulator screenshots, badging,
  logcat, and APK hashes.
- English and Spanish layouts remain complete.
