# v0.5.1 Local Beta Security Checklist

- Status: Active
- Issue: #108
- Related: #103, #101, ADR-0007
- Evidence: `docs/playtests/evidence/v051-security-*`

## Scope

This checklist covers the private, Tailscale-only five-person beta. It reviews
network exposure, secret handling, log and evidence redaction, tester data
handling, and dependency security before testers connect.

Out of scope: public deployment, Oracle, VPS, paid infrastructure, full
penetration testing, payments, and architecture changes.

## Threat model

- The repository is public, but the beta runs on a private Tailscale network.
- Testers are five known people, not the public.
- Assets: beta accounts, cloud saves, leaderboard entries, telemetry choices,
  remote config, and the development machine.
- Trust boundary: only the BFF is reachable by testers. PostgreSQL, Identity,
  Game, and Telemetry remain on loopback.

## Network exposure

| Service | Beta bind | Port | Consumer | Public Internet |
|---|---|---|---|---|
| BFF | Tailscale interface only | 5247 or the configured beta port | Five testers | No |
| Identity.Api | `127.0.0.1` | 5095 | BFF only | No |
| Game.Api | `127.0.0.1` | 5250 | BFF only | No |
| Telemetry.Worker | `127.0.0.1` | 5000 | none | No |
| PostgreSQL | `127.0.0.1` | dynamic or 5433 | backend only | No |
| Aspire dashboard | `127.0.0.1` | 15184 | operator only | No |
| OTLP | `127.0.0.1` | 19183 | operator only | No |

Rules:

- Never bind any beta service to `0.0.0.0`.
- Expose only the BFF, and only on the Tailscale interface.
- Do not enable a router port forward, UPnP, or a public reverse proxy.

### Verification result

- Identity.Api and Game.Api bound to `127.0.0.1` and were not reachable on the
  LAN address `192.168.3.8`.
- A manual PostgreSQL container published with `-p 5433:5432` was reachable on
  the LAN. The corrected `-p 127.0.0.1:5433:5432` was reachable only on
  loopback. This is recorded as finding F1.
- A second Tailscale peer reachability check runs in #101 before testers
  connect.

Evidence: `v051-security-port-bind-audit.txt`.

## Secrets

- `Jwt__SigningKey` and `ConnectionStrings__Database` come from environment
  variables or a local secret store, never from committed configuration.
- `.env` files are ignored; `.env.example` holds local defaults only.
- `deploy/secrets` stores SOPS-encrypted secrets only.
- Keystores, private keys, and tokens are never committed.
- Secrets never appear in logs, screenshots, or evidence.

Verification result: no tracked keystore or private key, no hardcoded signing
key, and only the secrets README tracked under `deploy/secrets`.

Evidence: `v051-security-secret-scan.txt`.

## Logs and evidence

- Access tokens, refresh tokens, passwords, save documents, and personal data
  are never logged.
- Evidence is redacted before it is committed.
- Only synthetic test-account values appear in committed evidence.

Verification result: no token, password, signing key, or connection string was
found in the reviewed evidence. Only synthetic test-account save values are
present.

Evidence: `v051-security-evidence-review.txt`.

## Tester data

- Testers consent to the data described in the beta plan.
- Telemetry is opt-in and defaults to off; opted-out clients send nothing.
- Raw telemetry events are retained for 30 days by the telemetry worker.
- Raw feedback and tester identities stay in the private beta channel.
- A tester may request deletion of their account, saves, leaderboard entries,
  and telemetry events.

Deletion procedure: one transaction removes telemetry events, leaderboard
runs, cloud saves, refresh sessions, and the account. The telemetry worker
recomputes the affected daily aggregate from the remaining raw events.

Verification result: the procedure was exercised with a test account. Before
deletion the account had one refresh session, one cloud save, and one
leaderboard run; after deletion all counts were zero and login returned `401`.

Evidence: `v051-security-deletion-exercise.txt`.

## Dependencies and containers

- Dependency audit: no vulnerable package after upgrading the AppHost SDK to
  `Aspire.AppHost.Sdk/13.6.5`.
- Container CI builds all four images and scans them with Trivy.
- The security workflow runs CodeQL and the dependency audit.

Evidence: `v051-security-dependency-audit.txt`.
