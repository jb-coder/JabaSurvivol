  - Tablet: 2560x1600 at 320 dpi

## Method

1. Started the local Aspire AppHost with the `http` launch profile and confirmed
   that every resource reached `Running`.
2. Built the emulator APK from `develop` with a `0.5.0` version override and
   recorded badging, checksum, and install evidence.
3. Installed the APK on the Android emulator and launched it with an
   `apiBaseUrl` intent extra pointing at the BFF through `adb reverse`.
4. Drove the account, cloud save, conflict, leaderboard, telemetry, and layout
   flows with real client requests and captured screenshots and logcat.
5. Created save conflicts through the public API to exercise both conflict
   choices, then confirmed the resulting cloud revision.
6. Restarted only the backend with remote-config environment overrides and
   reused the same APK to prove that flags change client behavior without a
   rebuild.
