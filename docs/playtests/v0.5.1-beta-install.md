- Version: `0.5.1` (version code `6`)
- Package: `com.jabasurvivol.game`
- Minimum Android: API 26 (Android 8.0)
- Target Android: API 36
- Orientation: landscape

## Install

### Phone or tablet with a file manager

1. Copy the APK to the device.
2. Allow installs from the file manager when Android asks.
3. Open the APK and confirm the install.
4. Launch the game and confirm `v0.5.1 · <commit>` at the bottom-left of the
   main menu.

### Phone or tablet over adb

```text
adb install -r JabaSurvivol-0.5.1.apk
```

`-r` replaces an existing install. The signing key must match the previous
install; the beta uses the project development keystore.

## Update

1. Install the new APK over the old one with the file manager or
   `adb install -r`.
2. Local progression is preserved because the package name and signing key do
   not change.
3. Open the main menu and confirm the new version and commit.
4. If the app reports a cloud-save conflict, choose `USE CLOUD` or
   `KEEP LOCAL`. The game never deletes local progression automatically.

## Uninstall

```text
adb uninstall com.jabasurvivol.game
```

Uninstalling removes the local save from the device. Back up through the
account panel first if the save is needed. A tester who leaves the beta can ask
the beta lead to delete the account, saves, leaderboard entries, and telemetry
events.

## Version and build identification

- The main menu shows `v0.5.1 · <commit>` in the bottom-left corner.
- The commit matches the build commit recorded in the beta evidence.
- Report the version, commit, device model, Android version, and layout with
  every defect.

## Network

- The beta backend is reachable only over the private Tailscale network.
- The beta lead provides the Tailscale invitation and the backend HTTPS URL.
- There is no public URL, Play Store listing, or app-store install.

### Bake the backend URL into the APK

Build the tester APK with the Tailscale HTTPS URL baked in:

```text
$env:JABA_API_BASE_URL = "https://<tailscale-host>"
pwsh tools/build/Build-Android.ps1 -OutputPath artifacts/android/JabaSurvivol-0.5.1.apk
```

The client reads the baked URL on startup, so a file-manager install works
without adb. Use the `tailscale serve` HTTPS URL; the client rejects cleartext
HTTP for non-loopback hosts.

### Launch with an adb intent extra

For an APK built without a baked URL, the beta lead can set the URL once at
launch:

```text
adb shell am start -n com.jabasurvivol.game/com.unity3d.player.UnityPlayerActivity --es apiBaseUrl https://<tailscale-host>
```

The override lasts for the current process. Relaunching from the home screen
without the extra falls back to the baked or production URL.

## Troubleshooting

- `App not installed`: the previous APK used a different signing key. Uninstall
  the old build, then install the new one. Local saves are removed by the
  uninstall.
- `INSTALL_FAILED_UPDATE_INCOMPATIBLE`: same cause as above.
- `INSTALL_FAILED_OLDER_SDK` or "App isn't compatible with your phone": the
  device is below API 26.
- `Server unavailable`: confirm Tailscale is connected, the beta host is
  running, and the APK contains the correct backend URL.
- Wrong version in the main menu: the old APK is still installed. Reinstall the
  file whose checksum matches the beta lead's value.
