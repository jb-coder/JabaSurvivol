# Local beta secret scan

- Date: 2026-11-11
- Issue: #108

## Tracked secret-like files

```text
git ls-files | Select-String '\.(keystore|jks|pem|pfx|p12)$|secrets'
deploy/secrets/README.md
```

Only the secrets README is tracked. No keystore, private key, or plaintext
secret file is tracked.

## Private key scan

```text
git grep -n -I -E "BEGIN (RSA |EC |OPENSSH )?PRIVATE KEY"
(no matches)
```

## Hardcoded signing key scan

```text
git grep -n -I -E "SigningKey\s*[:=]\s*[A-Za-z0-9+/]{16,}" -- src deploy
(no matches)
```

## Configuration

- `Jwt__SigningKey` is generated per AppHost run or supplied through the
  environment. It is never committed.
- `ConnectionStrings__Database` is supplied through the environment or a
  local secret store.
- `.env.example` contains documented local defaults only and is not a real
  environment file. Real `.env` files are ignored by `.gitignore`.
- `deploy/secrets/README.md` requires SOPS with age and forbids plaintext.

## Result

No secrets are committed. Secret handling uses environment variables or a
local secret store, and the beta plan forbids secrets in logs, screenshots,
and evidence.
