## Required review scope

- Meaning, tone, and game context for every changed string.
- Glossary compliance.
- Grammar, gender, accents, and punctuation.
- Placeholder and newline preservation.
- Missing, stale, or untranslated values.
- Phone and tablet screenshots for the changed screens.
- Truncation, overlap, and accented-glyph rendering.

Record findings by key and glossary reference. Target-language term changes
belong in `docs/localization/glossary.md`; keep this record in English.

## Release gate

A signed record is required before the Spanish locale can ship with these
settings strings. The agent reviewer and `reviewer-approval` check are not
linguistic review.
