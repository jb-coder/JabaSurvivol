# Playtest Records

This directory stores automated verification reports and optional human playtest notes.

- Beta plan: `v0.5.1-beta-plan.md`.
- Beta install guide: `v0.5.1-beta-install.md`.
- Beta security checklist: `v0.5.1-local-beta-security-checklist.md`.
- Feedback template: `beta-feedback-template.md`.
- Localization review records: `evidence/localization-review-<locale>.txt`.
- Localization layout evidence: `evidence/v060-layout-matrix.txt`.

Each record includes:

- Build version and commit.
- Device or emulator.
- Android version.
- Test duration.
- Locale or locales covered.
- Checks performed.
- Defects found.
- Screenshots or video references.
- Translation review status when the record covers localized strings.
- Verdict.

Automated verification is required. Human playtesting is optional and non-blocking unless explicitly requested.
